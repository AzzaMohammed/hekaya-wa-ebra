# حكاية وعبرة | كل حكاية تعلّمنا قيمة ✨

تطبيق ويب تفاعلي باللغة العربية (RTL) لتعليم الأطفال (4-9 سنوات) القيم الإسلامية من خلال القصص المستمدة من القرآن الكريم والسيرة النبوية، مع أنشطة وألعاب وتحديات عملية ونظام نجوم وشارات، ولوحة متابعة للأهل.

## المميزات
- 🏠 صفحة رئيسية مرحة: ترحيب، رفيق الطفل «سُهيل 🦉»، حكاية اليوم، قيمة اليوم، تحدي اليوم، شريط تقدم ونجوم
- 📚 مكتبة 10 قصص (7 دينية موثقة بالمصادر + 3 خيالية تعليمية موسومة بوضوح) مع بحث وفلترة حسب التصنيف والعمر والمفضلة
- 📖 قارئ تفاعلي: مشاهد متتابعة + استماع صوتي (Web Speech API) مع إيقاف + العبرة والمصدر
- 🎮 نشاط بعد كل قصة (اختيار من متعدد) مع شرح لطيف للإجابة
- 🎯 تحديات عملية يومية + زر «أنجزت التحدي» (+3 ⭐) — تشجيعية فقط وليست للحكم
- 🏆 نجوم وشارات (صديق الصدق، قلب رحيم...) وصفحة إنجازات — بلا مقارنة بين الأطفال
- 👨‍👩‍👧 منطقة أهل منفصلة ببوابة بسيطة: ملف الطفل، مستوى المحتوى، حجم الخط، الصوت، متابعة القصص والنتائج والقيم، أنشطة أسرية
- 💾 حفظ تلقائي في `localStorage` — يعمل دون خادم أو قاعدة بيانات

## التشغيل محليًا
افتح `index.html` في المتصفح مباشرة (الأفضل Chrome أو Edge ليعمل الصوت العربي).

## النشر على GitHub Pages
المشروع موقع ثابت (Static) — جاهز للنشر مباشرة من فرع `main`:
1. ارفع الملفات (`index.html`, `styles.css`, `data.js`, `app.js`, `.nojekyll`, `README.md`) إلى مستودع عام
2. من صفحة المستودع: Settings > Pages > Deploy from a branch > `main` > `/ (root)` > Save
3. الرابط سيكون: `https://USERNAME.github.io/REPO/`

أو استخدم سكربت `publish.ps1` (كليك يمين > Run with PowerShell) — ينشئ المستودع ويرفع الملفات ويفعّل Pages تلقائيًا عبر GitHub API (يحتاج Token بصلاحية `repo`).

## ملاحظات تقنية
- خط Cairo من Google Fonts (يحتاج إنترنت لأفضل عرض، ويعمل بدونه بخط بديل)
- الصوت عبر `speechSynthesis` — يعتمد على أصوات العربية في النظام/المتصفح
- الدقة الشرعية: القصص الموثقة مذكور مصدرها (السور وأرقام الأحاديث)، والخيالي موسوم بوضوح ولا يُعرض كديني
